### Added

- **The server can set the invite link role and reset the invite link.** The trip owner or an admin can set the link to admit editors or viewers, and can reset the link. When the link role goes up or the link is reset, a new code replaces the old one. The old link stops working. When the link role goes down, the code stays the same. A member who left and joins again gets the lower of their last role and the link role. The app does not show these controls yet. (#1012)
