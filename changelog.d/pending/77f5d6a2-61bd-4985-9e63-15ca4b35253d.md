### Added

- **Creators can link public posts to their live routes, and see which posts bring visits.** A creator adds an Instagram, YouTube or Threads link in the hub Profile tab. Each link has a route, an optional day and a short caption. The storefront shows a "From the posts" section only when posts exist. Each post has a tagged link, and the hub block "Posts bringing visits" counts the page visits that used it. The app stores links only. It fetches nothing from the platforms and keeps no visitor identity. The SQL is a draft that the operator has not applied. An operator must review and run it by hand.
