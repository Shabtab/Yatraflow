### Added

- **Four seasonal India trip cost calculators share one engine.** `/goa-trip-cost-calculator/`, `/rajasthan-trip-cost-calculator/` and `/meghalaya-trip-cost-calculator/` join the rebuilt `/ladakh-trip-cost-calculator/`. Each page is static HTML built from `calculators/`, so a crawler reads the same rupees a visitor sees. Every page shows a low to high range and keeps its numbers in the link. Each one carries `WebApplication` and `FAQPage` structured data, plus Vercel Web Analytics. `/trip-cost-calculators/` lists all four with their season and default estimate.
- **Every calculator hands its estimate to a trip plan.** The primary CTA passes the route, days, party size, transport mode, stay tier and per-person budget to `/new`. A signed-out visitor reaches sign-up with a banner that names their own estimate. Create Trip then opens with those fields filled.
- **`calculator` is a share-attribution value.** `ref=calculator` joins the vocabulary in `SHARE_SOURCES`, `api/i.js` and the SQL CHECK constraints. The migration `20261125_calculator_share_source.sql` widens both lists, so the value is refused until that file is applied.
